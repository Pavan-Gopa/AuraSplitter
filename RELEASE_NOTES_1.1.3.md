# AuraSplitter 1.1.3

## Исправлено

- **Кнопки стемов в Automation Matrix теперь нажимают только свою ячейку.** У каждой пары «трек × модель × стем» отдельная неперекрывающаяся область нажатия; нажатие больше не переключает стем другой модели.
- **Выбор означает “оставить”, снятие — “исключить”.** Во второй шаг попадают только явно выбранные и поддерживаемые выбранной моделью стемы; устаревшие и несовместимые значения удаляются без неявного выбора.
- **Строки второго шага сохраняют свою идентичность.** Изменения матрицы больше не пересоздают surviving Ready MIX rows, поэтому их выбор и итоговые имена не сбрасываются.
- **Короткие и итоговые имена редактируются и удерживаются.** Поля используют актуальное состояние Automation Wizard и сохраняют введённый текст после перестроения матрицы.

## Проверено

- Изолированный runtime-probe подтвердил точную маршрутизацию трёх model-scoped stem controls, стабильную идентичность второго шага, удержание имени, pruning и восстановление исходного состояния.
- Focused Matrix suite: 8 тестов, 0 ошибок. Полный Swift suite: 100 тестов, 0 ошибок.

## Обновление

- Установите из приложения: **Settings → Check for Updates Now**, либо через меню AuraSplitter. Апдейтер скачает zip, проверит подпись и SHA-256 и заменит текущую версию.
- Либо откройте DMG и перетащите **AuraSplitter** в Applications.
