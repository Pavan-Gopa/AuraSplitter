# AuraSplitter 1.0.9

## Исправлено

- **Приложение не находило Python.** В релизный `.app` теперь входит переносимый Python 3.11 runtime и все установленные backend-зависимости. Запуск больше не зависит от `.venv` и домашней папки разработчика.
- **Backend запускался по абсолютным путям разработчика.** Пути к Python, backend и launcher теперь разрешаются относительно ресурсов приложения; пользовательские каталоги используются только для моделей, логов и runtime-файлов.
- **Отсутствие Homebrew ломало обработку аудио.** В приложение добавлены `ffmpeg` и `ffprobe` с необходимыми библиотеками и относительными loader-путями. Обработка не требует отдельной установки Homebrew FFmpeg.
- **Backend runtime layout был неполным.** Релиз теперь запускает backend прямо из полного пакета, поставляемого внутри `.app`, без частичного копирования модулей.
- **Системная статистика перекрывалась аудиоплеером в компактном окне.** Левая панель получила вертикальную прокрутку; GPU, NPU и остальные показатели больше не наезжают на нижнюю панель.

## Проверка установки

- Поддерживается Apple Silicon macOS 13+.
- Пользователь запускает `AuraSplitter.app` из DMG; Python, зависимости и FFmpeg поставляются внутри приложения.
- Модели хранятся в пользовательском каталоге AuraSplitter и не дублируются в каждом обновлении приложения.
